## 🎯 What I Do

- Maintain a shared GitLab CI template library that development teams use for Java and Node.js services, with code quality and security scanning stages built in.
- Run GitOps delivery on OpenShift with Argo CD and Kustomize for digital banking services.
- Build and operate an AWS platform (Terraform, EKS, GitOps, secrets, monitoring) for the bank's travel app.
